Azure Fundamentals Study Tools AZ-900

Notes

  • Cost management: costs depend on resource type, consumption, region, bandwidth, and subscription type. Use the Pricing Calculator to estimate Azure costs, the TCO Calculator to compare with on-premises, and Microsoft Cost Management for analysis, budgets, and alerts. Reservations and Azure Hybrid Benefit lower the price, and tags group costs.
  • Governance and compliance: Azure Policy enforces standards and reports compliance, resource locks (CanNotDelete, ReadOnly) prevent accidental changes, Microsoft Purview governs data, and the Service Trust Portal holds audit reports.
  • Managing and deploying resources: the Azure portal, Cloud Shell, Azure CLI, and Azure PowerShell manage resources, Azure Arc extends management beyond Azure, and ARM templates and Bicep deploy infrastructure as code.
  • Monitoring: Azure Advisor gives recommendations, Azure Service Health reports platform issues and planned maintenance (Azure status, Service health, Resource health), and Azure Monitor collects metrics and logs with Log Analytics, alerts, and Application Insights.
