Azure Fundamentals Study Tools AZ-900

Notes

  • Core architecture: regions, region pairs, and availability zones provide the physical footprint. Resources are organized as management groups, then subscriptions, then resource groups, then resources, and policy and access are inherited down that tree.
  • Compute: virtual machines (IaaS), scale sets and availability sets for resilience, containers (Container Instances, AKS), App Service for web apps, Functions for serverless code, and Azure Virtual Desktop.
  • Networking: virtual networks and subnets, peering, VPN Gateway (encrypted, over the internet) vs ExpressRoute (private connection), Azure DNS, private endpoints, and network security groups.
  • Storage: Blob, Files, Queue, Table, and disks. Redundancy runs LRS, ZRS, GRS, GZRS. Access tiers are hot, cool, cold, and archive. Move data with AzCopy, File Sync, Data Box, or Azure Migrate.
  • Identity and security: Microsoft Entra ID, SSO, MFA and passwordless sign-in, Conditional Access, Azure RBAC, the Zero Trust principles, defense in depth, and Microsoft Defender for Cloud.
